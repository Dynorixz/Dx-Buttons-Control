# История изменений

## 1.1.2-ultra-test — 3 ноября 2026

Предварительный выпуск; опубликован на GitHub 10 ноября 2026.

- Узкий профиль Samsung Galaxy Watch Ultra SM-L705: `gpio_keys`, keyCode 264, scanCode 580, event/device sources 0x101.
- Проверки фактических manufacturer/model, descriptor, deviceId, isVirtual=false и целой пары DOWN/UP. Модель сохраняется в привязке; временный id не закрепляется после перезагрузки.
- Прежние профили pmic_resin и настройки сохранены. Home/Power защищены; перехват STEM_PRIMARY не включён.
- Добавлен 21 тест Ultra, всего 169 JVM-тестов.
- Подписанный release собран; новый APK на Ultra клиента ещё не проверен. Descriptor не виден на присланных фото и остаётся обязательной runtime-проверкой.

Публикация: README на русском и английском, реальные снимки UI, инструкции, архитектура, приватность, шаблон Issue и CI. Логика приложения и подписанный APK от 3 ноября при оформлении не менялись.

## 1.1.1-diagnostics — 2 ноября 2026

- Подробные InputDevice-поля и конкретные причины отказа вместо общей ошибки.
- Разделены неизвестные метаданные, виртуальный ввод и недопустимый профиль.
- Исправлена гонка холодного кэша: ограниченное асинхронное ожидание метаданных после UP.
- Локальное сохранение и JSON-экспорт отчёта; восстановление отчёта не создаёт привязку.
- 148 JVM-тестов, подписанная диагностическая release-сборка. [Исторический отчёт](docs/ULTRA_BUTTON_DIAGNOSTICS.md).

## 1.1.0 — 22 октября 2026

- Исправлены авторитетный снимок активного окна и переход на циферблат.
- Метаданные обновляются вне key callback; на API 33+ отключён кэш Accessibility-узлов.
- Устойчивые признаки циферблата вместо точной геометрии и динамических осложнений.
- Упрощены экраны, добавлено «О приложении» со ссылками Dynorixz Studio.
- Повторные двойные/тройные подтверждены пользователем на SM-L355F в debug; 118 JVM-тестов. Подготовлен release с R8. [Отчёт](docs/MULTIPRESS_FIX_1.1.0.md).

## 1.0.1 — 22 октября 2026

- Поддержан отдельный нижний драйвер pmic_resin при STEM_PRIMARY 264 / scan 580.
- Удержание запускается одноразовым таймером без ожидания повторного DOWN.
- Реальное удержание и штатное короткое Back подтверждены на SM-L355F; 94 JVM-теста. [Отчёт](docs/HOLD_FIX_1.0.1.md).
