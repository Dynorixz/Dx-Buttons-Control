# Galaxy Watch8 Classic SM-L505F

Локальная сборка Dx Buttons Control 1.1.5, versionCode 8. Профиль подтверждён отчётом клиента от 26 ноября 2026 года. [Модель в каталоге Samsung](https://www.samsung.com/uk/support/model/SM-L505FZWAEUA/).

| Поле | Данные отчёта 1.1.4-watch8-diag |
|---|---|
| Устройство | samsung SM-L505F, Android 16 / API 36 |
| Прошивка | BP2A.250325.020.L505FXXS3AZF4 |
| Кнопка и устройство ввода | STEM_PRIMARY (264), scan 580, gpio_keys |
| Источник | event.source и InputDevice.sources = 0x101 |
| Аппаратный канал | isVirtual=false, deviceId совпал с id устройства, descriptor непустой |
| Пара событий | DOWN и UP получены, downTime совпал, метаданные READY |
| Проверка | InputDevice пройдена. ButtonSafety отклонила модель с DEVICE_MODEL_UNVERIFIED |

В 1.1.5 модель SM-L505F добавлена в список допустимых моделей для gpio_keys. Код 264 допускается только в рамках аппаратного профиля, с прежними проверками scanCode, source, descriptor, устройства ввода и целостности пары. Home/Power защищены. Нажатия STEM_PRIMARY передаются системе; Dx наблюдает их для жестов. Профили Ultra, Watch6 Classic и pmic_resin сохранены. Уникальный descriptor из отчёта не используется как константа. При калибровке сохраняется descriptor конкретного устройства. Другие варианты Watch8 Classic требуют собственных измерений.

## Проверка у владельца

1. Установите APK 1.1.5 поверх подписанной 1.1.4-watch8-diag. Если появится приветствие, нажмите «Настроить позже» для перехода в главное меню. Проверьте, что служба Dx подключена.
2. В Dx откройте «Настройки → Кнопка и циферблат → Определить кнопку». Один раз коротко нажмите и отпустите нижнюю Back. Если экран закрылся, вернитесь в настройки кнопки.
3. Нажмите «Это нижняя кнопка». Проверьте удержание с назначенной вибрацией, штатное короткое Back и верхнюю Home.
4. На подтверждённом циферблате проверьте отдельно двойное и тройное нажатия с разными действиями.
5. Если привязка отклонена, пришлите новый «Отчёт кнопки». Если привязка есть, но действие не срабатывает, пришлите «Диагностику» после жеста.

Отчёт клиента подтверждает физическую доставку событий в прошлую версию. Установка 1.1.5 и выполнение жестов на SM-L505F ещё требуют проверки. Артефакты остаются локально.
