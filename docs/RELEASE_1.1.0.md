## Подпись и повторная сборка

Приватный ключ и параметры подписи хранятся отдельно от проекта в защищённом локальном хранилище автора. Машинные пути и секретные значения не публикуются. Для собственной сборки используйте внешний signing-файл: [BUILDING.md](BUILDING.md).

Для будущих обновлений необходимо сохранить этот ключ и параметры. Они не входят в исходники, обычные ZIP-архивы и облачные загрузки проекта. Публичный отпечаток сертификата приведён выше.

```powershell
.\scripts\BuildRelease.ps1 -SigningFile 'C:\Private\dx-release.properties'
```

Для другого компьютера укажите собственный путь к перенесённым signing-параметрам и актуальный путь `storeFile`. Новую пару ключей для обычного обновления создавать нельзя.

## Переход с debug

Release подписан новым ключом, поэтому Android не разрешит обновить debug поверх. Сначала экспортируйте настройки и сохраните JSON на компьютере или в другом месте вне данных приложения. Локальный JSON внутри `files/export` при удалении приложения тоже удаляется. После сохранения можно удалить debug, установить release, вручную включить службу, импортировать настройки и подтвердить нижнюю кнопку. Импорт специально сбрасывает аппаратную привязку и калибровку окна.

Для последующих выпусков release используйте этот же ключ и увеличивайте versionCode: переустановка со сбросом данных тогда не требуется.
