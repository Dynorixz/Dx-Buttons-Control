# Приватность и разрешения

Dx Buttons Control хранит настройки на часах. В Manifest нет INTERNET. В приложении нет аналитики, рекламы, учётной записи или собственного сервера. Авторские ссылки открываются по запросу пользователя на сопряжённом телефоне.

## Accessibility

Служба нужна для `onKeyEvent` и ограниченных метаданных окон, позволяющих отличить циферблат от приложений и меню. Она получает keyCode, scanCode, device/source, DOWN/UP и timestamps. Для окна используются package/class/resource ID, видимость, геометрия и ограниченная структура.

Приложение не читает node.text, contentDescription, event.text, тексты уведомлений, пароли, контакты или переписки. Снимки экрана службой не делаются. На API 33+ отключён системный кэш узлов; обход ограничен. Включение службы выполняет пользователь через Android.

## Остальные разрешения

| Доступ | Назначение |
|---|---|
| `VIBRATE` | Тактильный отклик и действие «Вибрация» |
| `QUERY_ALL_PACKAGES` | Локальный выбор приложения, включая пакеты без launch Activity |
| `WRITE_SETTINGS` | Выбранное действие системной яркости; нужен отдельный special access |
| `ACCESS_NOTIFICATION_POLICY` | DND при выданном доступе |
| `SET_ALARM` | Стандартные Intent таймера/будильника |
| NotificationListener access | Активные MediaSession для музыки; callbacks содержимого уведомлений не обрабатываются, категории доставки отключены |

`BIND_ACCESSIBILITY_SERVICE` и `BIND_NOTIFICATION_LISTENER_SERVICE` защищают компоненты: связываться с ними может система. Отчёт экспортируется через неэкспортируемый provider с временным доступом к файлу либо системный SAF.

## Локальные данные

DataStore содержит назначения жестов, тайминги, исключения, избранные/недавние пакеты, Quick Actions и профили. Последняя калибровка сохраняется в локальный JSON; диагностическая история ограничена в памяти. Системное резервное копирование отключено.

Отчёт кнопки содержит модель/производителя, API и сборку, версию приложения, события кнопки, имя и descriptor InputDevice, id/source/isVirtual, состояния lookup и причины отказа. Descriptor — идентификатор устройства ввода. Не публикуйте его вместе с посторонними личными данными.

Приложение ничего не отправляет автоматически. Перед отправкой отчёта проверьте содержимое. Полные системные logcat, снимки уведомлений, коды ADB-сопряжения и личные файлы для отчёта не нужны.

Сброс настроек и удаление приложения удаляют локальные данные; экспортированные файлы остаются в выбранном пользователем месте. Экспорт настроек и отчёт кнопки — разные файлы.

## Распространение

Репозиторий и APK распространяются через GitHub. Сетевая работа GitHub и браузера относится к этим сервисам; приложению на часах она для распознавания не нужна. Публикация в Google Play отдельно потребует деклараций Accessibility и широкого обзора пакетов.
