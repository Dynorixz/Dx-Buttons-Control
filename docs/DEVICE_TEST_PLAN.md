# План физических испытаний

Впишите модель, Android API, сборку, One UI Watch из системных настроек, настройки Back и наличие Pay/Wallet. Не переносите результаты с другой прошивки.

1. Установить debug APK. Включить Dx Accessibility вручную. Проверить статус подключения и конкурирующие key filters.
2. Калибровать только нижнюю кнопку. Записать KeyCode, ScanCode, InputDevice descriptor и наличие пары DOWN/UP. Проверить, что верхняя и средняя Quick-кнопки не подтверждаются ошибочно.
3. В режиме наблюдения сравнить штатный одиночный Back и системные сочетания с поведением при выключенной службе. Критически важные комбинации проверять по инструкции Samsung для конкретной модели; не инициировать экстренный вызов.
4. Записать сигнатуру циферблата и проверить индикатор на циферблате, в app drawer, уведомлениях, quick settings, плитках, редактировании циферблата и другом циферблате. Любое ложное совпадение означает необходимость удалить сигнатуру.
5. Назначить разные безопасные действия для удержания/двойного/тройного: сообщения с разным текстом или вибрацию. Проверять реальную кнопку, а не экранную проверку действия.

6. Для каждого порога 400/500/650/800/1000 мс: короткое, пограничное и длительное нажатие, повторные DOWN, отпускание. Указать, приходят ли повторы и срабатывает ли удержание во время нажатия или только на UP.
7. Интервал 350 мс: одиночное, двойное, тройное, 4 и 6 кликов, очень быстро и медленно, остановка после третьего DOWN, удержание после двух кликов. Тройное не должно выполнять действие двойного.
8. Во время комбинации открыть другое окно / заблокировать часы. Незавершённые жесты должны отменяться. Проверить выключение службы и восстановление настроек после перезапуска процесса / перезагрузки часов.
9. Проверить реальное исполнение и ошибки: удалённый пакет, приложение без Activity, отсутствие MediaSession, запрещённый Intent, отказ WRITE_SETTINGS/DND, unsupported global action. Сверить результат диагностики.
10. Проверить JSON экспорт/импорт, некорректный файл, сброс калибровки после импорта, избранные, недавние, 4–6 команд Quick Actions, touch и вращение рамки, крупный шрифт и минимальный круглый дисплей.

Опциональный перехват Back проверяется отдельно, только после прочтения ограничения в приложении. Сравнить Samsung «Назад» / «Недавние», эффект Pay/Wallet, потерянный UP, комбинации с другой аппаратной кнопкой. Не объявлять режим безопасным для системных сочетаний по одному успешному одиночному нажатию.

Состояния: «события получены», «жест распознан», «команда принята системой», «фактическое действие подтверждено» — отдельные наблюдения. Отсутствие callback не означает отсутствие физического нажатия. Не заполнять таблицу данными unit-тестов.
