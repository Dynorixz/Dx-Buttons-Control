# Двойное и тройное нажатия — 1.1.0

## Исправления

- Удалена зависимость свежего активного окна от номера последнего `TYPE_WINDOW_STATE_CHANGED`. При возврате Home прошивка может прислать только `TYPE_WINDOWS_CHANGED`. `WindowStateTracker` публикует новое активное окно, а результат запроса, устаревшего после другого события, отклоняет.
- Прежний сохранённый профиль «Недавние» больше не принимается за циферблат. Системный HOME определяется через PackageManager; нужны признаки хоста и полноэкранная видимая поверхность циферблата. Изменение осложнений и геометрии дерева не отменяет распознавание.
- Все запросы к дереву и состоянию дисплея вынесены из основного потока. В обработке клавиши используются сохранённые состояния экрана, окна и InputDevice. Для известных посторонних приложений, включая собственный Compose UI, не запрашивается даже root.
- На API 33+ отключены системный кэш и предзагрузка Accessibility-узлов. Root запрашивается без prefetch. Это исключает ненужные автоматические обновления узлов при событиях содержимого.
- Запросы обновления окна объединяются и выполняются последовательно. Выключение экрана немедленно сбрасывает распознавание; изменения Display учитывают возвращение из AOD.
- Двойное подтверждается с 80 мс допуска на очередь доставки третьего события. Логический интервал всё равно определяется `eventTime`; позднее отдельное нажатие не превращается в тройное за счёт этого допуска.

Нижняя кнопка SM-L355F по-прежнему работает в режиме наблюдения: все DOWN/UP передаются системе. Защита Power/Home и точная привязка `pmic_resin / scan 580` сохранены.

## Интерфейс

Главная страница содержит три компактные карточки жестов. Основные настройки жеста, дополнительные параметры и диагностика разделены. Список приложений включает поиск, иконки и избранное. В «О приложении» добавлены Telegram, GitHub и CloudTips автора; ссылки открываются через сопряжённый телефон с отображением результата.
