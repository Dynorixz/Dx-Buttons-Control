# Dx 1.1.4-watch8-diag

Локальная диагностическая сборка для Galaxy Watch8 Classic, versionCode 7. Package name и подпись прежних release сохранены. Профиль Watch8 Classic будет определён по измерениям клиента. При совпадении с имеющимся допустимым аппаратным профилем экран позволяет подтвердить нижнюю кнопку.

## Установка и проверка

1. Установите подписанный APK поверх прежнего release, затем откройте Dx. Версия 1.1.4-watch8-diag открывает экран «Тест кнопки».
2. Если «Служба Dx» выключена, нажмите «Включить службу» и включите «Dx · Управление нижней кнопкой» в системном меню. Вернитесь к тесту. Даже без службы тест может проверить, получает ли окно Dx событие или системный Back.
3. Нажмите «Начать тест» и один раз коротко нажмите нижнюю Back. Подождите до 14 секунд. Обычная навигация Back внутри этого экрана во время теста показывает результат вместо выхода.
4. Сфотографируйте итог, строки «Служба», «Окно Dx», «Системный Back» и модель часов. Если есть «Отчёт кнопки», откройте его и сохраните JSON или сфотографируйте причину отказа и источник события.

## Как читать результат

- Служба получила DOWN/UP и показывает DEVICE_MODEL_UNVERIFIED. Нужен точный код модели и аппаратный профиль из отчёта.
- Событие есть в окне Dx, но отсутствует у службы. Проверяется системная доставка в Accessibility и конкурирующие фильтры.
- Видно только «Системный Back». Android вызвал навигацию в приложении. Событие кнопки с аппаратными метаданными по проверенным каналам не наблюдалось.
- Служба включена в Android, но нет подключения. Проверяется запуск AccessibilityService отдельно от профиля кнопки.
- Ни один канал не отреагировал. Это результат данного теста. Отсутствие событий не определяет точную причину политики прошивки.

Диагностика не меняет правила аппаратной привязки. Home/Power защищены. Штатные жесты из версии 1.1.3 доступны из основного меню. Тест окна записывает только значения поддерживаемых кодов в память во время проверки. Отчёт службы переиспользует существующий локальный экспорт JSON.

Для воспроизведения сборки установите Gradle-свойство dxWatch8Diagnostic=true. Без него обычная версия 1.1.4 открывает основное меню. Физическая проверка Watch8 Classic ещё не выполнена, клиентские часы через ADB не доступны.
