# Galaxy Watch Ultra SM-L705: профиль gpio_keys

3 ноября 2026. Проверочная подписанная release-сборка **1.1.2-ultra-test**, versionCode 5.

## Подтверждённые данные

Пользователь передал фотографии диагностики клиента и указал модель **SM-L705**. На фотографиях видны:

| Поле | Значение |
|---|---|
| keyCode | KEYCODE_STEM_PRIMARY, 264 |
| scanCode | 580 |
| event.deviceId | 2 |
| event.source | 0x101 (257) |
| InputDevice.name | gpio_keys |
| InputDevice.id | 2 |
| InputDevice.sources | 0x101 (257) |
| InputDevice.isVirtual | false |
| lookup | READY |
| lookupError | нет |

**Подтверждённый отказ — несовпадение имени источника:** прежде STEM_PRIMARY разрешался только от pmic_resin. Проверки isVirtual и совпадения deviceId на этих фотографиях проходят. Descriptor на фотографиях не виден: его значение не придумано и не подставлено. APK получает его на часах; пустое значение по-прежнему отклоняется.

Модель семейства SM-L705 сообщил пользователь. Региональное обозначение SM-L705F относится к Galaxy Watch Ultra в [официальной документации Samsung](https://doc.samsungmobile.com/SM-L705F/030446240813/eng.html).

## Узкое правило

Новый профиль требует одновременно:

- Build.MANUFACTURER = samsung, без учёта регистра.
- Build.MODEL соответствует SM-L705 с необязательным одним региональным символом A–Z / 0–9; маркетинговые имена и другие семейства не подходят.
- InputDevice.name точно gpio_keys.
- keyCode 264, scanCode **только 580**.
- event.source и InputDevice.sources точно 0x101.
- descriptor непустой, InputDevice.id соответствует событию, isVirtual=false.
- Полная согласованная пара DOWN/UP; для этого профиля source не меняется между событиями.
- Пользователь отдельно подтвердил «Это нижняя кнопка».

Для новой привязки сохраняются фактически прочитанные manufacturer/model/source. При обработке нажатий проверяется реальная текущая модель, совпадение с моделью калибровки и точный descriptor. DeviceId **не закрепляется как 2**: после перезапуска системы он может измениться, поэтому сравниваются id текущего события и текущего InputDevice.

`ButtonSafety.allowed(264)` остаётся false. Home/Power/Sleep/Wake и другие зарезервированные коды запрещены; scan 116 и scan 114 для нового gpio-профиля не разрешаются. Виртуальный ввод не разрешается. Прежние pmic_resin / scan 580 и 114 работают по прежним правилам, без новой проверки модели. Старые настройки с четырьмя полями ButtonBinding читаются с безопасными значениями по умолчанию.

STEM_PRIMARY работает в наблюдении: DOWN/UP передаются системе. Режим перехвата для него не включается, исходное одиночное нажатие Samsung не подменяется.

## Проверка у клиента

1. Обновить release 1.1.0 или 1.1.1-diagnostics этим APK: сертификат прежний. Для перехода с debug сначала нужен отдельный экспорт настроек вне данных приложения.
2. В Dx открыть «Настройки → Кнопка и циферблат → Определить кнопку».
3. Коротко нажать и отпустить нижнюю Back, вернуться в Dx и нажать **«Это нижняя кнопка»**. Старый отчёт сам по себе не создаёт привязку.
4. Назначить на удержание вибрацию и проверить физическое удержание. Отдельно проверить обычное короткое Back и короткое нажатие верхней Home.
5. Двойное и тройное испытывать только на подтверждённом циферблате. Надпись о циферблате на экране настройки не является проверкой физической кнопки.
6. Если калибровка всё ещё отклонена, отправить полный JSON «Отчёт кнопки». Если привязка сохранена, но команда не срабатывает, нужны также «Обнаруженный жест / результат» из диагностики и описание фактического действия.

## Выполненные проверки и границы

169 JVM-тестов прошли, в том числе 21 новый для профиля Ultra: правильная модель и региональный суффикс, отказ другим моделям/производителям/источникам, Home/Power, scan 114/116, пустой descriptor, виртуальное устройство, смена source, сохранение действий и привязки, смена id после загрузки, чтение прежнего JSON. В тестах descriptor — явно обозначенная фикстура, не измерение с часов клиента.

Сборка assembleRelease и lintRelease успешна, 0 ошибок и 14 предупреждений. Подпись v2 и ZIP-выравнивание проверены; сохранён release-сертификат SHA-256 `7eeee74660625d66253b472c58f63cbe472edb1118ec537057d2962827714a6b`. R8 включён, отладочный флаг и INTERNET отсутствуют.

**Физическая работа нового APK на Ultra клиента ещё не подтверждена.** Данные для профиля получены из предоставленных фотографий; новую сборку нужно установить и повторить калибровку. Сборка и unit-тесты не заменяют эту проверку и не подтверждают все прошивки Ultra, AOD, выключенный экран, отсутствие конфликтов Wallet/Health или доступность циферблата.
