В тестах ActionExecutor используется контролируемый ActionPlatform: это проверка диспетчера, а не заявление о реальном запуске приложения на часах. Android adapter содержит публичные API вызовы и проверяется компиляцией/lint; физическая интеграция остаётся отдельной проверкой.

## Предупреждения lint

Семь предупреждений рекомендуют новые версии Gradle/BOM/Activity/Lifecycle/DataStore/Core. Зафиксированная конфигурация реально собрана; Wear Material 3 используется 1.7.1. Шесть предупреждений WearRecents относятся к `FLAG_ACTIVITY_NEW_TASK`: приложения/системные экраны запускаются из AccessibilityService или Application context, для которых этот флаг необходим. У внутренних Activity выставлены отдельные taskAffinity; временные Activity исключены из Recents и помечены noHistory. Lint baseline и глобальное отключение проверок не используются.

В build log присутствует сообщение о сохранении debug native symbols двух библиотек зависимостей; оно не является ошибкой сборки. ZIP alignment не объявляется самостоятельной проверкой ELF-поддержки любой прошивки.

## Перед заявлением о совместимости с конкретными часами

Выполнить [DEVICE_TEST_PLAN.md](docs/DEVICE_TEST_PLAN.md): подтвердить физическую нижнюю кнопку, проверить положительный и отрицательные экраны сигнатуры, все три жеста, штатный одиночный Back, Wallet/Pay/Health, исключения и восстановление после перезапуска. Успешная сборка не гарантирует, что прошивка передаёт события нижней кнопки. В наблюдении удержание без repeat запускается после UP; при недоступной сигнатуре циферблата двойной/тройной отключены. Эти границы описаны в [COMPATIBILITY.md](docs/COMPATIBILITY.md) и показаны в приложении.
