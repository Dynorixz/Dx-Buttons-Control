## Предупреждения lint

Семь предупреждений рекомендуют новые версии Gradle/BOM/Activity/Lifecycle/DataStore/Core. Зафиксированная конфигурация реально собрана; Wear Material 3 используется 1.7.1. Шесть предупреждений WearRecents относятся к `FLAG_ACTIVITY_NEW_TASK`: приложения/системные экраны запускаются из AccessibilityService или Application context, для которых этот флаг необходим. У внутренних Activity выставлены отдельные taskAffinity; временные Activity исключены из Recents и помечены noHistory. Lint baseline и глобальное отключение проверок не используются.

В build log присутствует сообщение о сохранении debug native symbols двух библиотек зависимостей; оно не является ошибкой сборки. ZIP alignment не объявляется самостоятельной проверкой ELF-поддержки любой прошивки.
